# UFO's Cheat Mods Bundle for Bannerlord [1.4.7] - No War Sails

This branch packages the maintained Bannerlord v1.4.7 update without a War Sails/NavalDLC dependency. It is a separate Workshop module from the War Sails edition and must not be enabled alongside it.

All gameplay features and compatibility fixes are shared with the maintained v1.4.7 edition. The original mod and bundled work remain credited to UFOdestiny and the original authors below.

> **Testing status:** The maintainer uses the War Sails edition, so this no-War-Sails build has not been gameplay-tested. It compiles successfully without any NavalDLC reference or dependency and should theoretically work, but it should be treated as an early test release.

My original goal was to learn how to make mods. It just so happened that the 'crush through' feature I wanted stopped working, so I decompiled it and combined it with several well-known mods. I noticed that many people were also sad about some wanted features no longer working, so I decided to release this mod directly.
